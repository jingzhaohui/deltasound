# ============================================================
# DeltaSound — Equalizer APO 配置（三角洲行动 · 听声增强复刻）
# 复制到 C:\Program Files\EqualizerAPO\config\config.txt 后用 Peace / Configurator 生效
# 只支持立体声 48kHz；游戏内请关闭所有音效增强、7.1 虚拟环绕
# ============================================================

# EQ 一共抬升约 +11dB，先留 headroom，交给后级 limiter 收尾
Preamp: -4 dB

# --- 1. 风声 / 环境低频轰鸣 ---------------------------------
# 2 阶高通，切掉 140Hz 以下稳态隆隆；切太高性能损失"震感"
Filter 1: ON HPQ Fc 140 Hz Q 0.707
# 低频驻波/闷响轻微收一点（稳态噪声抑制的静态部分）
Filter 2: ON PK Fc 90 Hz Gain -2.0 dB Q 1.0

# --- 2. 震感：爆炸 / 载具低沉震动（副作用：盖住脚步） ---------
Filter 3: ON PK Fc 220 Hz Gain 2.5 dB Q 0.9

# --- 3. 脚步：落地厚实声 --------------------------------------
Filter 4: ON PK Fc 420 Hz Gain 1.5 dB Q 1.2

# --- 4. 静步：蹲走轻脚步（副作用：人声/枪声变响） -------------
Filter 5: ON PK Fc 1600 Hz Gain 2.5 dB Q 1.0

# --- 5. 路面：铁板/木板/碎石质感 -------------------------------
Filter 6: ON PK Fc 3200 Hz Gain 3.0 dB Q 1.2

# --- 6. 细碎声：草丛/衣物摩擦（副作用：更刺耳，别拉满） -------
Filter 7: ON PK Fc 6500 Hz Gain 2.0 dB Q 1.0

# --- 7. 去刺：枪声齿音区静态兜底 -------------------------------
Filter 8: ON PK Fc 9500 Hz Gain -2.5 dB Q 1.0

# ============================================================
# 档位速查（把上面对应 Gain 换成下表数值）
#   档位      F1 HPQ   F3 220  F4 420  F5 1.6k  F6 3.2k  F7 6.5k
#   轻         120Hz    +1.0    +0.5    +1.0     +1.5     +0.5
#   标准       140Hz    +2.5    +1.5    +2.5     +3.0     +2.0   ← 当前
#   较强       160Hz    +4.0    +2.5    +3.5     +4.0     +3.0
#   强         180Hz    +5.0    +3.5    +4.5     +5.0     +3.5
# 「细碎声」超过 +3dB 会明显发刺，与「防炸耳」冲突，建议 ≤ +3。
# ============================================================

# --- 8. 防炸耳（动态部分，Equalizer APO 原生没有压缩器） --------
# 两条路二选一：
#  (a) Peace GUI 挂 VST：ReaComp(thr -18dB, ratio 4:1, atk 3ms, rel 120ms)
#      → ReaLimit(ceiling -1.0dB)；参数在 VST 面板里设一次即可。
#  (b) 用同目录 index.html 的实时原型跑完整动态链（含瞬态增强、
#      稳态风声抵消、高频去刺、限幅），配 VB-Cable / BlackHole 虚拟声卡。
# Equalizer APO 的 VST 行形如（路径按本机实际改，取消注释启用）：
# VSTPlugin: "C:\Program Files\VSTPlugins\ReaComp.dll"
# VSTPlugin: "C:\Program Files\VSTPlugins\ReaLimit.dll"
# ============================================================
