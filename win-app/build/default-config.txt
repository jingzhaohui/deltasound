# 覆盖到 C:\Program Files\EqualizerAPO\config\config.txt
# 曲线依据「三区脚步频段模型」与低频向上掩蔽原理，详见 docs/RESEARCH.md
# 只处理静态 EQ；风声抵消 / 向上压缩 / 动态去刺 / 前瞻限幅需实时链或 VST

Preamp: -6.5 dB

# 切次低频 rumble（20–80Hz 是最强掩蔽源），保留 150–450Hz 脚步体感与楼层线索
Filter 1: ON HPQ Fc 125 Hz Q 0.707
# 低架衰减：削减低频向上掩蔽，比提高频更有效且不会让枪声变刺
Filter 2: ON LSC Fc 120 Hz Gain -3.5 dB Q 0.70
# shallow scoop：500–800Hz 浑浊/箱声区
Filter 3: ON PK Fc 700 Hz Gain -2.0 dB Q 1.40
# Zone1 撞击 / Zone2 材质 / Zone2-3 瞬态方位 / Zone3 碎物距离
Filter 4: ON PK Fc 220 Hz Gain 1.0 dB Q 1.10
Filter 5: ON PK Fc 420 Hz Gain 1.8 dB Q 1.20
Filter 6: ON PK Fc 1600 Hz Gain 1.8 dB Q 1.00
Filter 7: ON PK Fc 3200 Hz Gain 2.4 dB Q 1.40
Filter 8: ON PK Fc 6000 Hz Gain 1.0 dB Q 1.00
# 6–12kHz 承载距离线索，只做 1dB 轻架；刺耳声交给动态去刺
Filter 9: ON HSC Fc 10000 Hz Gain -1.0 dB Q 0.70

# 动态处理（Equalizer APO 原生不支持），两条路二选一：
#  (a) Peace GUI 挂 VST：ReaComp(thr -18dB, 4:1, atk 3ms, rel 120ms)
#      → ReaLimit(ceiling -1.0dB, lookahead 1.5ms)
#  (b) 用同目录 index.html 的实时链 + VB-Cable / BlackHole 虚拟声卡
#  完整参数：向上压缩 -24dBFS(全带宽慢包络) / 2.5:1 / 上限 +14dB / 底噪门 -58dBFS；
#            枪声动态去刺 2.5–9kHz 最多 -9dB；侧信号最多 +4dB
# 风声压制=70%  防炸耳=70%  侧向定位=50%

# ============================================================
# 档位速查（把上面对应数值替换；Preamp 恒定 -6.5dB 留 headroom）
#   档位   HP(Hz)  LSC   MUD   F4/220  F5/420  F6/1.6k  F7/3.2k  F8/6k  HSC
#   轻       100   -2.0  -1.0   +0.5    +1.0    +1.0     +1.5    +0.5   -0.5
#   标准     125   -3.5  -2.0   +1.0    +1.8    +1.8     +2.4    +1.0   -1.0  ← 当前
#   较强     135   -4.5  -2.5   +2.0    +2.5    +2.5     +3.2    +1.8   -1.0
#   强       140   -5.5  -3.0   +3.0    +3.5    +3.0     +4.0    +2.5   -1.5
# 「细碎声」6kHz 超过 +3dB 会明显发刺；8kHz 以上不宜再抬（听力疲劳）。
# 任何档位总提升都在 +10dB 以上，必须配合后级限幅，否则会削波。
# ============================================================

# --- 防炸耳 / 静步（动态部分，Equalizer APO 原生没有压缩器） --------
# 两条路二选一：
#  (a) Peace GUI 挂 VST：ReaComp(thr -18dB, ratio 4:1, atk 3ms, rel 120ms)
#      → ReaLimit(ceiling -1.0dB, lookahead 1.5ms)。参数在 VST 面板里设一次。
#      注意：压缩器务必设为「立体声联动」，逐声道独立会破坏左右定位。
#  (b) 用同目录 index.html 的实时原型跑完整动态链（向上压缩 / 稳态风声抵消 /
#      枪声动态去刺 / 侧信号增强 / 前瞻限幅），配 VB-Cable / BlackHole 虚拟声卡。
# Equalizer APO 的 VST 行形如（路径按本机实际改，取消注释启用）：
# VSTPlugin: "C:\Program Files\VSTPlugins\ReaComp.dll"
